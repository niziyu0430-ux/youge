# 游格理解测试 试用与后续研究操作方案

当前所有玩家样例均为虚构。下面是待开展的真实试测方案，没有把自动检查、模拟报告或公开研究的结果算作本项目的样本。

## 第一阶段 12人理解测试

目标是确认参与者怎样理解题目。初步覆盖PC单机、PC联机、主机单机、主机联机各三人，并在各组兼顾较少与较多游戏经验；这些是招募配额，不代表总体抽样。

每人完成一次正常流程并口述理解。主持人不先解释维度、不提示期待答案，也不把更高分描述成更好。可用以下开场：

> 这里没有正确答案。请按你通常喜欢的体验回答。我们主要想知道题目有没有让你误解，或有没有你想表达但选项表达不了的情况。

逐项任务如下：

1. 随机抽取每维至少一题，请参与者用自己的话复述。
2. 请其解释3分与无法判断／不适用的区别。
3. 分别用反例检查：只为奖励清图、只想赢别人、只想优化效率、会合作但不需要社交、最近疲劳但平时不追求舒缓。
4. 检查一人能否同时喜欢探索和查攻略、挑战和舒缓。
5. 请其说明平台不支持Mod、没时间二刷时怎样填。
6. 核对喜欢、拥有、玩得久和通关之间是否被混淆。

记录题号、复述原话、误解类型、所选答案、犹豫点和建议措辞。若至少两人将同一题理解成设备、能力、道德评价或近期状态，重写该题并安排新的理解核对。不要为降低不适用率而逼参与者猜答案。

## 第二阶段 120人小规模试用

冻结题库、计分和文案版本后招募120人。保留招募来源、主要平台、接触机会和清单长度；按参与者计数，重复提交只保留预先规定的一次有效记录，并报告处理流程。

主要检查项目：

| 项目 | 记录方式 | 修订方向 |
|---|---|---|
| 时长 | 说明结束、开始核心题、作品完成、追问结束的时间；暂停单列 | 默认三款路径中位数目标≤10分钟，同时报告P90；超时先压缩追问负担 |
| 缺失 | 每题缺失及原因、每维有效数 | 检查适用性和表达，而非补零或补中间值 |
| 中立 | 每题3分比例、全卷分布 | 区分真实中立、难理解和内容未覆盖 |
| 内容重复 | 参与者指出的重复及题间关系 | 同维保留不同情境，避免只换措辞 |
| 维度关系 | 各维分布、相关和初步内部一致性 | 结果只用于修题；不因某个系数达标就宣称结构已验证 |
| 称号 | 各展示类别数量、单题翻转情况 | 调整展示规则并保留版本对照 |
| 报告理解 | 能否找出三条判断的答案依据；去名后是否仍有差异 | 删除泛化赞美、没有证据的推断和重复说明 |

时间从正式开始答题至追问结束计算，不包括阅读个人报告。扩展五款作品路径、研究人格模块和跨游戏任务分别统计，不合并进6—10分钟承诺。

八维结构仍待在较大独立样本中验证。探索性分析修改题目后，不能再用同一批数据作为独立确认。

## 第三阶段 40人两周重测

从试用者中邀请40人，在14±3天再次完成相同版本核心题。重测先答题，再查看之前的报告；记录是否曾查看、讨论过原报告，以及主要游戏、时间条件或近期精力有无明显变化。

按维报告成对有效人数、两次分数分布、重测相关和绝对分差。单列称号变化、主副角色变化，以及首测敏感性标记与变化之间的关系。相关高不等于两次分数一致，称号一致也不能代替维度稳定性。

缺失不填补。主分析使用两次对应维度均至少三题有效的数据；另检查相同有效题集合和实际间隔符合窗口的结果。退出和逾期人数单独列出，不为得到更好的稳定性指标而事后删人。

## 后续研究A 口味与游戏偏好

### 输入和预设指标

口味侧只使用玩家明确喜欢的作品，主分析先限定亲自体验过的作品。合并同一作品身份，保留版本和系列；未知身份不猜测归类。

作品原始重合使用Jaccard：交集作品数／并集作品数。另按同一研究样本中的作品出现频率加权：

`w(g)=ln((N+1)/(n_g+1))+1`

其中N是独立参与者数，n_g是列出作品g的独立参与者数。加权重合为交集权重和／并集权重和。空清单没有相似性信息，不设置为完全相似。

游戏画像主指标为八维平均绝对分差：`mean(|A维度分−B维度分|)`。主分析要求八维均有效；补充检查去除个人总体打分高低后的形状距离。研究标准化不回写产品分数，也不生成玩家百分位。

`youge/research.py`提供上述描述指标，用于未来离线研究；产品单人和双人报告不调用它们，也不展示成契合度。

### 接触机会与混杂因素

除B01平台、B02接触玩法外，正式研究增加独立的机会记录：对冻结候选作品分别记录是否知道、是否有机会接触、是否亲玩及是否喜欢；不知道和无机会不算不喜欢。机会模块在核心题之后，另计时长。

分析考虑作品热度、平台重合、接触机会、双方清单长度及同系列作品。至少保留以下分析：原始重合与热度加权重合；仅亲玩与包含期待；系列折叠前后；清单长度统一后的重复抽样；不同招募来源与平台。

主分析可先限定双方至少两款亲玩喜欢作品，减少只有一款时的极端值；少于两款者仍可使用产品报告，并进入单列的敏感性分析。该筛选在采集前固定，报告人数及适用人群。

### 双人依赖与结果解释

每位参与者出现在多组配对中，配对数量不是独立样本量。以参与者为单位划分数据并重采样，重建配对矩阵；去掉个体与自身的边，不独立抽配对行。正式分析冻结包含上述协变量的双人模型，并以参与者层面的重采样给出不确定性。

报告效应大小、区间、样本来源和敏感性分析，而不只报告显著与否。关联不写成游戏决定人格，也不把作品吸引点与核心题的自述吻合当作独立验证。[双人相似性方法研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3771326/)

## 后续研究B 口味与现实人格

独立人格模块自愿参加，可退出，不影响玩家报告。冻结的起点是IPIP官网Sih-Ci Jhu繁体中文50题译本及官方样例计分键。原译文、英文、题序、反向映射、来源URL和抓取内容摘要值保存在`research/ipip50.zh-Hant.source-v1.json`。[中文译本](https://ipip.ori.org/ChineseAB5CFactorMarkers.htm)、[官方样例及计分键](https://ipip.ori.org/new_ipip-50-item-scale.htm)、[公开使用说明](https://ipip.ori.org/newPermission.htm)

保持第四因子的情绪稳定性方向，第五因子的智性／想象命名。反向题使用6减原分；不能把情绪稳定性直接当作未经反向处理的神经质，也不替换成MBTI维度。

如制作简体版本，逐条记录调整、核对含义并做理解测试，另存适配版本；不继承其他中文译本的效度结论。正式研究主分析按原键处理五因子，缺失不填补，未参与者只进入研究A。

独立人格模块在玩家个人结果展示前完成，记录顺序，避免报告文案直接引导人格自述。已经看过报告的参与者单独标记，不与未看过者混称同一种研究条件。

分别检验作品重合与独立五因子画像的关系，再探索游戏偏好是否解释额外差异。研究A与B分开报告；群体相关不转化为个人现实人格判断。多个次要维度检验预先固定并控制多重比较，不能事后只挑关联最大的结果。

## 跨游戏研究任务

另行自愿邀请参与者选择两款玩法不同、亲自体验过的作品，分次按指定作品填写相同核心内容。参考期仍覆盖近半年至一年，但研究说明明确只回顾当前作品；因此保存为研究语境版本，不冒充常规总体版。

记录作品、填写顺序、间隔、近期条件与有效题。两款作品顺序进行预先安排或随机平衡，比较人内变化与人际差异，不把整体问卷自述直接当成跨游戏稳定性的证据。研究语境版不发常规原型称号。

## 研究启动前的冻结与记录

正式假设验证另做预注册：固定主要指标、排除标准、控制因素、抽样方式、分析模型、多重检验及独立样本量。样本量根据预设最小效应和功效模拟确定；不能把120人内容试用自动升级成正式验证。

记录模板见`research/study-record-template.json`。它只定义字段，未包含真实参与者或研究结果。所有反馈、缺失、退出、版本修改和偏离方案的情况都留记录。
