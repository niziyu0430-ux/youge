# 游格计分 原型与特殊答卷规则

本版规则对应配置`display_rules`及参考实现`youge/engine.py`。阈值用于展示连续偏好，均待试测修订。

## 核心计分

维度分＝25×（该维有效题平均分－1）。每维四题等权，至少三题有效才计算；不适用、无法判断及跳过不进入总和或分母。有效答案只接受1—5整数，不能用0、字符串或布尔值代替缺失或评分。

例如：EXP四题为5、5、5、4，总和19，平均4.75，维度分93.75，显示93.8。若为5、5、4、null，平均14/3，维度分275/3，约91.6667；仍有三题有效，允许计分。若只有两题有效，该维分数为null。

输入只包含核心答案对象；作品、吸引点、补充标签、背景和追问没有进入计分函数的接口。所有输出称为问卷偏好分，无常模、不计算玩家百分位。

保留总和、有效题数、平均值与未舍入分。显示采用十进制四舍五入至一位小数，例如6.25显示6.3；称号比较使用精确分数值，显示舍入不会改变分类。`fractional_gap`与`fractional_outside`分别覆盖约8.3333分和10.4167分的分差，检查10分门槛内外的判读。每维三题或四题等权时，原始分差的最小公共步长为25/12，恰好10分的差距实际无法由这些答案产生。

## 基础称号的处理顺序

按以下顺序处理，先匹配者生效：

1. 任一维度少于三题有效：局部画像，不给完整主副型。
2. 八维均达到75分：全高，展示多面倾向，不强排主副。
3. 八维均不超过25分：全低，不给确定原型，提示可结合补充清单检查覆盖。
4. 最高维度低于60分：暂无明显主型。
5. 其余答卷建立领先组：达到60分且与最高分相差不超过10分的维度。

领先组一维时形成暂定主型。其他维度中达到60分的最高项为副偏好；最高项精确并列时全部保留。领先组两维时双主并列；三维以上时多面倾向。内部ID顺序只安排显示，不制造高低。

## 中立 重复和缺失

有效答案中3分达到75%时显示中立信息提示。中立是实际回答，不等于未知。某一维仍有明确支持时，不能因其他题中立而抹去局部证据。

同一选项占有效回答75%及以上时记录分布，不自动判无效。全高、全低和全中立都可能是需要解释的回答，不能仅凭答案模式推断敷衍。

缺失原因单独保存为无法判断、不适用、没有选择余地或选择不回答。未提供原因也保留为缺失，不填成0或3。缺失维度在图中显示资料不足，不能画成零长度低分条。

## 单题敏感性

对每道有效核心题，枚举其合法范围内的减一档、加一档；1只能上调，5只能下调。null不参与该枚举，不把补答问题混同于一档变化。

每次重新计算基础称号，与原答卷比较三个对象：主型或领先组、副偏好集合、展示类别。四题有效时该维改变6.25分；三题时约8.3333分。

呈现规则为：

- 主型稳定且副偏好稳定：按基础规则显示。
- 主型稳定但副偏好易变：保留主型，取消副偏好确定排序，展示相关维度分。
- 主型或领先组可能变化：显示暂定偏好组合，取消确定主副角色。
- 局部、全高、全低、无明显主型本身已弱化称号，保留对应说明；变化情况仍存入审计数据。

JSON保存所有导致变化的题号、原值、新值及变化后的基础称号。该检查不是统计置信度、准确率或重测概率。阈值调整后应更新计分版本，并重新运行全部例子和验收。

完整画像有缺失或没有可枚举的有效答案时，稳定性字段为null，显示资料不足。不能因为没有观察到称号变化就写成称号稳定。

## 报告判断不等于称号规则

称号门槛60分不意味着可以直接撰写广泛的性格描述。首版跨场景维度判断另需：该维达到75分，且至少两道不同情境题选择4或5；实际引用这些题目与维度计算。组合判断分别满足两个维度的条件。

这也是可配置文案条件，不是经过验证的科学界限。单条行为追问只解释相应具体选择。低分不能生成能力不足或厌恶；消耗判断只使用明确负面原因和回避边界。

完整条件、文案与证据选择器保存在配置`report_rules`；作品解释、摘要和同游安排规则登记在`derived_report_rules`及`advice_topics`。同样答卷和同样版本得到同样判断。
