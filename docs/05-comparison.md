# 游格双人对照报告规格

双人对照帮助两人理解共同口味和本次同游安排。它不计算性格契合度，也不从共同作品数量推断相处质量。

## 输入和版本

输入为两份各自独立填写的完整答卷及报告。先核对题库、计分、文案和作品字典版本。本版兼容映射为空；版本不一致时保留各自结果，不合并条形图或比较数值。

每个引用加左侧或右侧命名空间，防止相同题号混淆。所有具体对照保留双方原始选择、证据引用、触发快照和规则ID。

## 四个固定部分

共同作品按作品ID及版本对齐。别名可归并；续作、重制和不同版本保留身份信息。同作不同版本单独列出，不假定技术兼容。未填入清单只说明未报告，不说明不喜欢。

同一作品并排展示双方最多两项吸引点，以及是否亲自体验。共同作品但原因不同，是报告应保留的信息。双方都未亲玩也可以记录期待重合，但不能称为共同的实际玩法。

八维图使用相同0—100坐标，分别显示有效题数。分数由各自核心答案计算，共同作品不调整分数。缺失维度显示资料不足，不补零，不形成整体契合度。

最后逐项列出同游协商。状态仅有已有共同选择、需要协调、资料不足；它们描述明确回答和当前安排，不是关系评价。

## 七项协商的确定性规则

| 主题 | 依据 | 判读和建议 |
|---|---|---|
| 剧透 | G02 | 两边明确时比较剧情／谜底许可；先采用双方都允许的信息范围。有人要求逐次确认时，先问本次边界。 |
| 剧情 | P02 | 同选项标共同选择；不同则确认共同停留、各自体验或同意后略过。 |
| 难度 | P03 | 比较明确安排，不把挑战分数换成技术水平；不同答案先商定初始难度和调整时机。 |
| 探索推进 | P01 | 比较本次节奏选择；不从探索分差直接判定矛盾。 |
| 攻略 | G01 | 相同用途集合可标重合；不同用途需确认查阅时机；剧透许可另看G02。 |
| Mod | M01及M02 | 使用条件受限时先确认可行性；双方无意愿可先按原玩法；只有条件或经历而无用途时资料不足。用途与实际／假设依据分别比较。 |
| 失败后的安排 | P04 | 比较继续、复盘、查资料、调整或暂停的直接回答，约定何时切换。 |

一方未答、缺乏经历、不适用、跳过或无法判断时，对应项目显示资料不足，给出待确认建议。不能把缺失解释成愿意配合，也不能自动认定意见一致。

两边同答“先协商”代表都希望先协商，不等于具体难度、剧情或Mod方案已经确定。所谓已有共同选择只覆盖当前题目表达的粒度。

## 示例与验收

[A与B](../reports/A-B.md)的三款作品相同，但吸引点、画像和多项安排不同。[A与C](../reports/A-C.md)没有共同作品且画像相同，仍有剧情、难度和失败安排需要协商。

验收包含：中文别名与英文名能匹配；不同版本单列；只有观看期待不能写成实际共同经历；核心分数改变但追问不变时，协商状态不应凭分差变化；无共同作品时不写口味相反；任一版本不兼容时不合并。
