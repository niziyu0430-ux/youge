## 当前测试路径

首页 → 搜索一款库内、确实玩过并喜欢的作品 → 16道四选一 → 必要时最多两道四选一补问 → 一个明确的人格外号与独立3D角色。正式题没有第五项、多选或后续表单；键盘A—D可作答。

作品库47类，每类20款，允许跨类重叠；未知作品不能直接开始，在选定类别后推荐库内相近类型作品。八款专用题包为文明6、荒野大镖客2、死亡搁浅、死亡细胞、杀戮尖塔、骑马与砍杀2：霸主、天国拯救2、潜水员戴夫。其他作品使用16类机制模板。作品名称只选择场景，不直接给人格加分。

人物图鉴包含16幅独立人物。报告以性格侧写为主，区分愿意二刷但时间不足、新作品优先、平台不支持Mod等情况。可回看修改正式答案、保存完整PNG长图、打印PDF、导入导出JSON答卷，与另一份本地档案或虚构示例对照8项同游安排，不生成契合度百分比。

题库、计分和作品版本为0.4.0，侧写文案为0.4.1。固定权重与固定补问规则保证同一版本、同一答卷的核心结果一致；唯一称号是产品分类，不是经过真人验证的准确率。详见 `13-v0.4-questionnaire-and-scoring.md` 和 `14-v0.4-trial-and-review.md`。

# v0.3 历史说明

## 开始测试

双击项目根目录的 **启动游格.cmd**，会在本机启动服务并打开 `http://127.0.0.1:8765`。需要 Python 3.10 或更新版本，网站本身没有第三方运行依赖，也不需要 npm 安装。

命令行亦可启动：

```powershell
python -m youge.web --port 8765
```

服务只绑定 `127.0.0.1`，不会发布到公网或局域网。端口被占用时可以用 `--port 8767`；启动器支持 `powershell -File scripts/start_local.ps1 -Port 8767`。换端口视为另一个浏览器存储空间。

## 已实现的完整路径

首页 → 32段具体游戏场景 → 0—5款作品及每款最多两个吸引点 → 补充体验 → 适用性选择及条件追问 → 玩家报告。

核心题五个选项全部描述具体行为，不附“更接近某种倾向”的提示，不展示维度名或计分方向。独立“不适用”不会当作中立答案。可以返回上一题、暂存离开、刷新继续；键盘 A—E 可选择当前题。

作品可以少填或全部留空；不要求内置作品字典中存在。作品、吸引点、平台、攻略、二刷和 Mod 均不计入八维分。条件追问遵循原配置，明确区分没时间二刷和不想二刷、Mod 平台限制和用途意愿。

报告包括原型摘要、可展开的真实答案依据、横向八维坐标、跨作品吸引力、享受与消耗、七项同游建议，以及游戏外自我核对。可回看核心答案并重新计算。没有证据时留空说明，不编造三条判断。

可下载本机生成的完整 PNG 长图、打印为 PDF、导出和导入 JSON 答卷。双人对照使用两份本地档案、另一人导出的答卷或标注虚构的 A/B/C 示例，比较共同作品、原因、独立画像和七项协商，不计算契合度百分比。

## 版本与研究边界

题库 `0.3.0`、计分 `0.2.0`、文案 `0.3.0`、作品字典 `0.2.0`。v0.2 的五点陈述题本次改成五个具体行动选项，题义与作答方式发生了实质改变，因此单独冻结为新题库。保留原有配置、文档、模拟答卷及压缩包。

这次版本仍是待理解测试和试测的原创模型。不能把旧版的测量结论直接迁移过来，也不把这次界面可运行当作效度证据。后续继续执行理解测试、120人试用和两周重测计划，重点补查五个行动选项是否构成同一目标的合理程度梯度，以及情境是否需要不适用。

演示 A/B/C 仅为检验界面、证据和规则的虚构答卷，已迁移为当前题号版本；不是新版题库的真人数据或验证证据。旧版 JSON 不静默按新版题义解释，导入时要求四部分版本完全匹配。

## 本地数据

答卷由浏览器发送到本机 Python 服务计算，服务不持久化答案、不调用生成模型、不发往外部服务。草稿与最近12份档案保存在当前浏览器的 localStorage。导出的 JSON 含作品、答案和昵称，方便玩家自己保留和用于双人对照。

草稿存储键为 `youge-local-v0.3-draft`，档案为 `youge-local-v0.3-history`，编辑其他档案前暂存的未完成旅程为 `youge-local-v0.3-paused`。浏览器清除站点数据会影响这些记录；完整答卷可以重新导入。

## 代码入口

- `youge/web.py`：本机静态文件与 JSON 接口，复用确定性引擎。
- `config/youge.v0.3.0.json`：32道场景题、选项及独立规则。
- `web/app.js`：流程、暂存、导入导出和结果展示。
- `web/poster.js`：以同一报告数据绘制 PNG。
- `web/styles.css`、`web/DESIGN.md`：响应式布局与设计约定。
- `web/assets/README.md`：原创背景来源、生成方式及完整提示词。
- `tests/test_web.py`：内容约束、证据映射、HTTP 接口及版本边界。

运行 `python -m unittest discover -s tests -v` 检查旧版与网站版。UI 实测使用独立端口，避免给正式预览留下模拟答题进度。
