# 游格作品库 v0.5：扩充、中文检索与版本关系

更新日期：2026-10-28。作品数据发布为 0.5.0；现有问卷、计分和答卷数据契约继续兼容 0.4，报告文案版本仍为 0.4.1。

本轮按用户确认的范围执行：原生 PC 游戏优先，保留已有知名主机作品；有独立 PC 客户端的跨平台作品可以收录，不新增手机专属或仅通过模拟器运行的作品。分类不设数量上限，奖项、提名和好评不再是入库的必备条件。

## 当前交付

- 公开库与分类：[完整清单](../exports/游格-游戏分类清单.md)。数量由构建器实时生成，不在页面写死。
- 待核实作品：[候选清单](../exports/游格-待核实游戏候选清单.md)。候选不出现在新选择游戏的搜索结果中。
- 实际运行数据：[games.v0.5.0.json](../config/games.v0.5.0.json)。含公开条目、候选、来源、别名证据和版本关系。
- 构建统计：[build-summary.json](../research/catalogue-v0.5/build-summary.json)。归类关系和作品条目分开统计；版本条目也不冒充不同的独立作品。

## 名称与受众口径

1. 商店或发行方给出中文名时，保存中文名称及来源。
2. 中文媒体、游戏资料库或玩家社区中已有通称时，保存其使用出处，标为中文资料通称；不把媒体或社区译名标成官方译名。
3. 用户已确认：没有可核实中文译名，但至少有 **50 篇中文 Steam 评测**的作品，允许保留。此类条目显示“原文品牌名（中文类型说明）”，括号内容是说明，不是译名。
4. 缺少中文名称依据，中文受众证据也不足或尚未取得的作品，先进入候选。

中文评测是筛选证据，不是对中文玩家总体知名度的测量。批量商店接口的语言汇总使用简体中文；针对原库的补充核对同时查询简体、繁体中文。每条记录的 `language_scope` 保留实际请求口径。缺失数据不伪装成零条评测。

`aliases` 是搜索用词，包括中英文名称、简繁体变体、常见简称和系列数字写法。`name_evidence` 与 `alias_evidence` 区分商店名称、资料通称、编辑检索词和字形转换。简称可有歧义，因此搜索返回候选作品供用户确认，不自动替用户选游戏。

## 原作与版本

原版、重制版、高清版和内容存在差异的修订版保留独立 ID，以 `work_id`、`version_type`、`version_label`、`related_games` 关联。明确区分的例子包括：

- 《生化危机4》原版与 2023 重制版。
- 《死亡空间》2008 原版与 2023 重制版。
- 《上古卷轴5》原版与特别版。
- 《侠盗猎车手5》传承版与增强版。
- 《暗黑破坏神2》原版与《狱火重生》。

CSGO 使用独立作品条目，不再作为 CS2 的精确别名。豪华版、年度版等同一作品的商品名称可以作为检索别名，但不能把续作当成原作的别名。对无法核实的版本关系，不凭相似名称自动合并。

原库把《Out of the Park Baseball》25 代名称关联到 27 代商店 ID 的错误已纠正。修正有单独记录，避免把两个年份混为同一作品。

## 搜索与兼容

- 支持中文、英文、常见简称、简繁体、全半角、标点和部分系列数字变体。
- 短英文简称优先精确匹配，避免 LOL 被任意英文单词中的连续字母误命中。
- 分类数量、条目数和分页从实际数据计算，每页数量不限制分类容量。
- 分类内没找到、但全库有结果时，提供“在全部分类搜索”。
- 未找到时提示换名称并给出有限的推荐，不把推荐误当成用户心里的游戏。
- 已有 0.4 答卷的游戏 ID 和机制题包保持兼容。原库中的待核实条目通过内部兼容入口保留，仍可读取旧答卷。
- 新作品使用现有机制模板；本轮没有改变计分权重或编造真人试测结果。

## 来源与重建

当前运行不请求外部服务。商店身份、PC 平台、标签与语言评测汇总冻结在 `research/catalogue-v0.5/`；不保存评论正文、评论者账户或个人资料。

主要入口为 Steam 商店与公开元数据接口，以及腾讯、网易、暴雪、西山居、盛趣等发行方页面；历史作品可采用 MobyGames 等资料来源，并明确来源性质。网页核对与自动采集分别保留，采集失败的发行方链接不会伪装成成功返回。

只使用已冻结资料重建：

```powershell
python scripts/build_expanded_catalogue.py
python -m unittest discover -s tests -q
```

需要显式更新外部资料时：

```powershell
python scripts/seed_expanded_catalogue.py
python scripts/research_expanded_catalogue.py --stage all
python scripts/research_publisher_catalogue.py
python scripts/build_expanded_catalogue.py
```

公开接口可能变化或限流。采集脚本有节流、缓存与冷却；发生失败时保留待核对状态。原始 0.4 数据和历史生成器保留用于追溯，当前库维护以 `build_expanded_catalogue.py` 为入口。

## 验证与覆盖率

全量 125 项测试通过，覆盖数据引用完整性、候选隔离、旧答卷兼容、原版／重制版区分、简称及简繁体搜索等。在真实浏览器中，21 组代表性搜索全部通过，分类回退正常，390 像素宽手机视口没有横向溢出；另核对新增的《英雄联盟》可以从搜索进入 16 题答题流程。

浏览器核对的实际结果保存在 [catalogue-ui-validation.json](../output/playwright/catalogue-ui-validation.json)，桌面与手机截图分别见 [桌面](../output/playwright/catalogue-editions-desktop.png)、[手机](../output/playwright/catalogue-editions-mobile.png)。

上述检查验证数据与产品行为，**不能证明已经覆盖 97% 的中文 PC 玩家最爱游戏**。该指标仍需冻结库版本后，用独立且能代表目标玩家的自由填写样本，计算命中率和置信下限。用户补录不能倒算为该次搜索前已经收录。
