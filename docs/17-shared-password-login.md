# 游格共用密码登录版 v0.5.0

## 买家怎样使用

买家打开网站后先看到访问密码页。输入共用访问密码后进入首页，在当前页面内可以不限次数测试。浏览器刷新、关闭后重新打开、新建标签页或退出登录后，都需要再次输入密码。

答题草稿与档案仍按原规则保存在当前浏览器；它们不会替代登录验证。重新登录后，原有草稿可继续。

## 卖家怎样使用

1. 在交易平台完成交易后，手动把网站链接和当前共用密码发给买家。
2. 当前本地试用地址：`http://127.0.0.1:8765/`。
3. 当前共用密码保存在工作区外网不可访问的本地文件 `.local/access-password.txt`，可打开复制。
4. 修改密码请在项目目录运行 `python -m youge.access set-password`，按提示输入两次。不要只修改密码文本文件；该文本仅方便卖家查看，验证配置是 `.local/access.json`。
5. 密码更新后无需重启服务。已有登录会在下一次请求时失效，需要使用新密码重新登录；正在浏览的内容不会主动抹除，题目与结果接口继续检查新权限。

这版采用所有买家共用的密码，不按购买订单单独发码。测试次数不设上限。服务端为无活动清理和控制会话表大小保留12小时会话寿命；超过后重新输入密码即可继续，不影响已存草稿。

## 登录状态与刷新规则

- 浏览器每次加载HTML文档都得到登录页，包括首页、v4入口、旧版入口和人物对照页；编码路径也做同样处理。
- 登录成功后，服务端生成256位随机访问令牌。前端在当前文档的ES模块内存中保存，使用Authorization请求头调用接口。
- 不把密码或登录令牌写入Cookie、localStorage、sessionStorage、URL或浏览器历史记录。
- 登录成功通过经过授权的app-shell接口加载页面，并在当前文档启动应用，避免用跳转重载页面而马上丢失登录状态。
- 刷新会创建新的文档内存，不能继承旧页面令牌。离开页面时尽力撤销旧令牌，后退缓存恢复也重新加载登录入口。
- 首页配置、题目、示例、报告、对照，以及旧版对应接口均要求服务端验证。健康检查和页面所需的静态JS/CSS/品牌图片公开提供；图片授权不等同于防复制或DRM。

## 密码与访问保护

验证配置使用带随机盐的PBKDF2-HMAC-SHA256（600000次），随机令牌仅保存校验哈希。参数参考[OWASP密码存储说明](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。卖家密码提示文件含明文，放在不对外服务的`.local`内并被版本控制忽略，应按卖家凭证保管。

错误登录按连接源IP计数：10分钟内累计8次错误，暂停60秒，并返回Retry-After。并发密码计算有数量限制。跨站提交、配置路径读取、URL／Cookie伪装令牌都不能获得测试权限。会话设计参考[OWASP会话管理说明](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)。

## 本地与线上

当前仍是本地Python预览服务，不是买家可访问的公网网址。正式售卖前需要线上部署、域名和全站HTTPS；多进程部署还需共享会话存储或匹配的会话路由。反向代理的真实来源IP必须按可信代理配置，不能直接相信客户端传入的X-Forwarded-For。HTTPS要求见[会话传输说明](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html#transport-layer-security)。

## 实现与验证

- `youge/access.py`：密码生成、修改、哈希验证、会话、错误次数限制。
- `youge/web.py`：登录入口、受保护接口与受保护应用外壳。
- `web/access.html`、`web/access.css`、`web/access.js`：暖白、墨蓝与珊瑚色登录页，手机布局与错误提示。
- `web/access-client.js`：仅当前文档存在的访问状态、请求头、退出和刷新生命周期。
- `tests/test_access.py`：真实HTTP权限检查、重复测试、错误登录限制、退出、密码轮换和新文档内存检查。
- 修改前的相关源码保存在 `design/v0.5.0/site-before/`。

当前137项测试通过。主服务额外验证了登录页、正确密码、受保护首页外壳与配置、以及退出失效流程。

浏览器实测通过：错误密码提示、成功登录、查看报告、进入正式答题、答题中刷新回到登录页、重新登录后继续草稿，以及退出登录。320和390像素手机视口下，登录表单无横向溢出，390像素下已完成登录及退出操作。验证记录与截图保存在 `design/v0.5.0/`。
