# 游格玩家人格测试完整实施规格

版本0.2.0。首版面向中文PC与主机玩家，描述游戏偏好与行为倾向。常规测试、研究测量与虚构验收数据分别记录。

## 核心假设与成功标准

待检验假设是：喜欢作品越相似，独立测得的游戏偏好可能越相似；喜欢这些作品的原因可能解释相似或差异。现实人格关系另做自愿、独立测量。

产品需要让玩家读懂三件事：不同喜欢作品的共同吸引力，同一作品里的不同玩法与相处方式，以及可能跨作品存在的通常偏好。去掉原型名称后，报告仍要保留具体差异和安排建议。

情境题独立形成八维；作品名、类型、吸引点、补充体验和条件追问均不进入计分。报告可以记录两份自述的呼应，也允许不一致，不能以吻合自证模型有效。

借鉴MBTI容易记忆、讨论和分享的表达方式。本模型使用八个非对立维度与八个基础原型，未设计四组对立或16型。类型动力学不作为开发重点。所有核心题为本项目原创；不使用官方MBTI题库和计分键。

## 已落实的问卷流程

说明→32道固定交错核心题→默认三款、可填零至五款喜欢作品→可选一款亲玩但未喜欢作品→补充体验清单→背景与模块适用性→最多12道按需追问→报告。

统一参考过去一年，优先近半年、有选择余地时的通常偏好。核心题先做，避免作品和吸引点选项提前引导回答。背景题放在核心题后。每维四题，使用1—5统一评分，null单独表示无法判断、不适用或未回答；不把现实条件、能力或近期疲劳代替兴趣。

八维为探索发现、叙事沉浸、挑战精进、竞技胜负、策略规划、创造表达、社交联结、舒缓体验。题目覆盖与逐题解释见[完整问卷](02-questionnaire.md)。

作品默认三项，允许少填、全部跳过、最多五项。每项保存明确喜爱自述、亲玩状态及最多两项吸引点，可补充原话。拥有、时长和通关不用于替代喜爱。补充清单含即时爽感等十项，只生成标签。

## 测量与展示的分工

八维按有效核心题等权计算；每维至少三题有效。原型称号由连续画像摘要而来，不要求每份答卷都有主型。60分、10分分差、全高全低及中立提示均作为可配置展示规则。

有效性不足时保留局部画像；并列保留并列；全高不强排主副；全低允许识别覆盖缺口；中立和重复回答不自动判为无效。逐题±1档枚举主型、副偏好及类别是否变化，再决定是否弱化称号。详见[计分规则](03-scoring.md)。

每条具体判断保存规则、触发快照及实际答案依据。多个情境的概括至少有两个不同情境的正向答案支持。具体行为追问只能支持相应习惯。没有明确负面回答时不从低分生成消耗点。

## 报告交付形态

单人报告依次包括原型摘要、最多三条有依据的具体判断、固定0—100横向条形图、作品共同吸引、容易享受及有明确依据的消耗点、七项同游建议、最多两项现实习惯核对问题。尾部附原始答案、逐维计算、追问状态和敏感性复算例子。

双人报告依次展示共同作品、各自吸引点、独立八维分及七项协商。共同作品不转化为契合度百分比，画像差异不转化为合作能力或冲突结论。不同版本无明确兼容映射时分开显示。

JSON保留完整证据与未舍入数值；Markdown供人工阅读；PNG与SVG均使用固定坐标。常规生成不调用生成模型，不联网决定结果。完整规则与文案见[原型及报告手册](04-archetypes-and-reports.md)。

## 当前边界与后续工作

本阶段完成内容规格、参考计分与报告实现、配置、样例与机械验收。网站、账号、真实玩家招募和假设检验尚未开展。时间目标为常见三款作品路径6—10分钟，试测后决定对外承诺。

后续先开展12人理解测试、120人小规模试用及其中40人的14±3天重测。题意和规则修订均更新版本。正式结构验证和口味关联分析使用后续独立样本，按预注册方案执行。

## 十项验收如何落到交付中

| 要求 | 交付与验证位置 |
|---|---|
| 同作品可有不同画像 | A与B的原始答卷、单人报告及双人对照 |
| 不同作品可有相近画像 | A与C分数逐项一致，作品列表不同 |
| 作品替换不影响计分 | 自动检查作品、吸引点、补充清单等变更前后的分数与原型 |
| Mod条件不改变创造表达 | C与A创造表达分相同；M01不属于计分输入 |
| 时间限制不同于不愿二刷 | A、C与B的R01和R03触发不同规则 |
| 边界不强行贴型 | 十一份专项原始答卷、边界报告及枚举检查 |
| 单题称号敏感性 | 对每份答卷枚举合法单题±1档，保存完整变化 |
| 去掉名称仍有差异 | 比较具体判断、作品原因和七项同游建议 |
| 判断依据真实存在 | 每条报告判断都经过证据引用检查 |
| 同版本结果可重复且可复算 | 固定配置、版本、答卷指纹、逐维算式和重复生成检查 |

实际执行结果见[验收记录](../reports/verification.md)。自动检查不替代真实试测或核心假设验证。
