# 作品库来源与冻结口径

本目录按用户提供的分类图片整理47个唯一分类、940条归类、753款作品。`taxonomy.json`保留原图48个位置的映射；`shortlist.json`保留每类20个作品的作者选择。主运行配置是 `config/games.v0.4.0.json`，正常打开网站不联网查询Steam。

Steam产品名称与评测汇总来自官方商店与公开的IUserReviewsService接口；仅保存汇总，不保存具体评论、评论者账号或用户ID。接口口径为全部语言、Steam购买用户、过滤题外评测的冻结快照，不能冒充所有平台总口碑。采集遇到429时等待Retry-After／冷却时间，未绕过限制。

发布配置中677款取得非零评测汇总，2款没有非零汇总；46款保留发行方或主机平台来源，25款保留另行核对的商店身份参考，3款名称匹配但评测请求未完成。全部753款有来源链接，未完成的比例留空，不填零或沿用别款作品数据。

入库以知名度与口碑为主、类内代表性为补充，优先获奖。少量知名系列的PC版本评价混合，保留实际数值，不宣传为全库一致好评。未填奖项不代表没有获奖。`awards.json`只记录本轮从TGA主办方历史页核对的获奖条目；原作奖项不证明后来的移植版本质量。

数据生成：`scripts/build_v04_catalogue.py`将冻结记录合并为网站配置；`scripts/build_v04_deliverables.py`生成完整目录与文档。`research_catalogue_v04.py`是显式更新来源的采集脚本，不应在用户答题时运行。

作品名和分类不直接给人格加分；其用途是选择题包、匹配搜索与解释题目适用性。
