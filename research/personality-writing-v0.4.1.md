# 人格侧写的公开参考与写作取舍

查阅日期：2026-10-27。

参考了 [Myers & Briggs Foundation类型概览](https://www.myersbriggs.org/my-mbti-personality-type/the-16-mbti-personality-types/) 以及下列16Personalities公开介绍。Architect等外号来自16Personalities，未把其测量框架、MBTI或游格16类一一对应。学习的是叙述如何展开动机、思考、关系和代价；游格正文围绕自己的游戏动机原创，没有翻译或替换原文人格名。

| 查阅的介绍 | 留意的写作方式 |
|---|---|
| [INTJ · Architect](https://www.16personalities.com/intj-personality) | 动机如何形成判断，并影响相处 |
| [INTP · Logician](https://www.16personalities.com/intp-personality) | 把思考过程写成连贯的行动方式 |
| [ENTJ · Commander](https://www.16personalities.com/entj-personality) | 追求、行动与协作代价来自同一习惯 |
| [ENTP · Debater](https://www.16personalities.com/entp-personality) | 尝试可能性，也讨论完成与承诺 |
| [INFJ · Advocate](https://www.16personalities.com/infj-personality) | 价值需要与关系边界一起展开 |
| [INFP · Mediator](https://www.16personalities.com/infp-personality) | 连接认同、意义和实际行动 |
| [ENFJ · Protagonist](https://www.16personalities.com/enfj-personality) | 关心与介入之间有需要协商的边界 |
| [ENFP · Campaigner](https://www.16personalities.com/enfp-personality) | 外在活力之后仍有深层需要 |
| [ISTJ · Logistician](https://www.16personalities.com/istj-personality) | 从约定和实践写出持续的行为逻辑 |
| [ISFJ · Defender](https://www.16personalities.com/isfj-personality) | 细节与长期投入，以及付出的边界 |
| [ESTJ · Executive](https://www.16personalities.com/estj-personality) | 结构可以支持行动，也需要接纳差异 |
| [ESFJ · Consul](https://www.16personalities.com/esfj-personality) | 重视回应，同时允许不同期待 |
| [ISTP · Virtuoso](https://www.16personalities.com/istp-personality) | 直接经验、个人节奏与沟通方式 |
| [ISFP · Adventurer](https://www.16personalities.com/isfp-personality) | 表达、自主与他人评价的关系 |
| [ESTP · Entrepreneur](https://www.16personalities.com/estp-personality) | 即时行动与后果之间的取舍 |
| [ESFP · Entertainer](https://www.16personalities.com/esfp-personality) | 共同感受与长线安排的联系 |

落地结构为“你的性格底色”“与你相处的方式”两个主板块；各人格同时保留动机、选择方式、值得留意的代价与相处建议。问卷中的明确习惯只作简短个性化补充，不堆回攻略、Mod、二刷等独立卡片。

表达中避免天生聪明、道德高低、职业命定、诊断、现实关系结论等无依据断言。游戏中的投入方式提供解读视角，现实中的自己可以认同、修正或保留不同意见。
