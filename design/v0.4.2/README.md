## 生成与验证记录

使用内置 `image_gen` 原图编辑，共生成18张：16张当前版本和2张修订前样图。没有使用API/CLI生成，也未对生成图进行程序化改色、裁剪或抠图。所有当前图均为1024×1536 RGBA，透明范围已检查；项目引用全部指向工作区内副本。

- `portraits-manifest.json`：16张当前图的源文件、版本、原图、提示词索引和SHA256，另记录两张旧样图。
- `generation-sources.json`：全部18次输出来源。
- `generation-prompts.json`、`generation-prompts-batch1.json`、`generation-prompts-batch2.json`、`generation-prompts-batch3.json`、`revision-prompts.json`：完整逐角色提示词。
- `wardrobe-plan.json`：最终配色与轮廓规格。
- `asset-validation.json`：16张当前图的尺寸、模式、透明范围和本地服务路径核验。
- `site-before/`：接入图片切换前的前端源文件副本。
- `scripts/build_v042_art.py`：复制生成文件并构建清单；不编辑图片像素。
- 自动验证：118项测试通过；另核对浏览器内原版／新装切换、刷新保留、角色详情、双章报告与1080×2198长图预览。
