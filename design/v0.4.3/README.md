# 首页与手机端优化 0.4.3

首页顺序：顶部导航 → 16人人物滚动栏 → 原有主视觉与开始按钮 → 页脚。

滚动栏仅展示画像和名字，两组等宽内容衔接，CSS线性无限循环，实际速度约36像素/秒。悬停、触控按住、查看人物介绍时暂停，也可使用暂停／继续按钮。

移除旧四人卡片、三步流程展示、首页测试数量说明和已答题数说明。已有答题状态保留，继续按钮仍可恢复进度。

作品库、人格图鉴、问卷、结果和对照页左上方提供返回首页；档案、人物介绍等弹窗也提供同风格入口。

## 手机适配

检查320、375、390、430、768、844像素宽度，均未出现页面横向溢出。320像素极窄屏导航会换行，其他常见手机尺寸保持单行。此为浏览器尺寸模拟检查，不是真机Safari兼容性认证。

系统启用减少动态效果时，关闭自动动画并提供手动横向浏览。键盘进入人物栏时停下动画，把当前人物滚入视野。

## 图片交付

滚动栏用320×480透明WebP。V2全套16张合计708258字节，V1为756532字节。仅缩放与编码，不修改原版画像；点开介绍仍用原尺寸图。原图哈希已核对一致。

重建：`node scripts/build_ribbon_assets.mjs "<bundled node_modules directory>"`

`web/assets/personas-ribbon/manifest.json` 保存32张衍生图的来源、尺寸、大小和原图／输出哈希。支持WebP的浏览器使用小图，其他浏览器通过picture元素回退原PNG。本地服务显式提供image/webp类型，避免Windows注册表将其识别为通用二进制。

## 实现文件

- `web/v4-home.js`：简化后的首页。
- `web/v4-ribbon.js`：人物栏渲染、暂停、键盘与减少动态支持、监听清理。
- `web/v4-home.css`：人物栏、返回按钮和手机布局。
- `web/v4.js`：页面接入，返回首页时关闭弹窗并保存草稿。
- `site-before/`：本轮修改前的前端源文件副本。

## 验证

119项测试通过。浏览器核对了作品库、人格图鉴、档案弹窗、问卷与结果页的返回首页入口；答完第1题返回首页后可继续第2题。跨循环测得约36.003像素/秒，暂停位置保持不变。
